# DexTrail release history

## 1.0.1 — 2026-10-29

Smoother PokéAPI updates

- Fixed PokéAPI updates getting stuck on “Checking for updates · 1 of 5.”
- Checks now use PokéAPI’s official data files and reuse unchanged downloads to keep repeat checks fast.
- Added clearer progress and connection messages. Pausing an update responds promptly, even if the connection stalls.
- Incomplete checks keep your existing data safe and can be retried.
- Updated the privacy-policy link to the DexTrail website.
